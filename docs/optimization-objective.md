# 单件装备的优化目标与评分

状态：Phase 0 数学架构审阅稿，2026-11-03。遵循[启动规范第 6–8 节](../BOOTSTRAP.md)及用户确认的等权预算、固定宏路线与失手即停止约定。本文的权重和排序是产品定义，不是游戏掉落事实。

## 1. 评价对象和预算

只优化当前给定的一件装备。起始底材、词缀与 FP 类型固定；不包含购买替代品、失败后换底材重新开始，也不把不同 FP 类型当成可自由转换。

公开输入没有玩家实际剩余 FP。评价器内部按 D={1,…,B} 分别模拟假设预算；当前版本的 setter、生成／赋能路径和序列化审计确认持久化普通装备 B=63，故默认域为 1…63，见[打造审计](research/forge-fp-audit.md)。未来版本仍由对应快照给出 B，不能从 byte 字段宽度推断。F=0 单独给边界结果，不进入默认评分。

默认 w(F)=1/B。高级配置可以指定有穷预算域与非负权重，必须至少有一项正权重并在评价前归一化；所有路线共享同一输入和同一权重配置。结果原样列出预算域和权重，既不猜玩家真实 FP，也不宣称它们代表自然掉落分布。

## 2. 首要评分

令 S 表示该单件按固定路线 R 执行后成功，P_R(F)=P(S|R,F)。

~~~text
J(R) = sum_F w(F) P_R(F)
~~~

J 是假设预算混合下的完成概率。先选择同一个 R，再对所有 F 求值。不得先为每个 F 或每个随机中间状态分别取最优，再把所得包络当成一条可执行路线。

已满足目标的起点可返回空路线，所有预算下成功率为 1、消耗与阶段数为 0。无可行路线、输入本身不合法、所限语言内已证明不可达、搜索未完成但尚未找到路线，必须用不同状态表达。

## 3. 统计口径

对于预算 F，记录实际净 FP 消耗 C_F、每种材料实际消耗 G_j,F、制作尝试数 A_F，以及 S 的联合分布。

~~~text
p_F = P(S | F)
m_F = E[C_F | F]
u_F = E[C_F · 1_S | F]
d_F = E[C_F · 1_failure | F]

p = J(R)
m = sum_F w(F) m_F
u = sum_F w(F) u_F
d = sum_F w(F) d_F

E[C | success] = u / p              # p > 0
E[C | failure] = d / (1−p)          # p < 1
~~~

成功条件混合均值必须用 u/p。将各预算的成功条件均值直接按原始 w 平均，会忽略“成功样本中的预算构成”已经被 p_F 改变。

总消耗 C 的 CDF 为 sum_F w(F)P(C_F≤c|F)；成功条件 CDF 为 sum_F w(F)P(C_F≤c,S|F)/p。二者均报告 P50／P90／P95。没有成功样本时成功条件指标为 null；不能用 0 表示。

制作的全部实际消耗都统计，包括最终未完成的路线；不是“每次成功前重买材料直到成功”的多件装备成本。critical 等材料退款从对应投入中减掉，Hope／Ice 零 FP 本身不表示零材料。尝试数仍计算该次制作。

## 4. 材料代价

对每种材料记录 debit、refund、consumed=debit−refund 和 recovered。critical 返还本次投入不算 consumed；剥离得到的碎片属于 recovered，单列产出。库存递推会加入这些产出，但默认评分不把它们折成负成本。

~~~text
MaterialCost(R) = sum_j price_j · sum_F w(F) E[G_j,F | F]
~~~

price_j 默认均为 1，只表达“实际消耗件数等权”，不冒充市场价格或稀缺程度。用户可以提供非负相对权重及库存限制。默认 inventory=unbounded 及独立的 usageLimits 会随结果公开；有限仓储和用户自限不能合并，因为原生额外加阶资格也可能读取仓储余额。每种碎片保留稳定 ID；不把所有碎片预先合并为可互换材料。

## 5. 确定性词典序

在主评分无法区分后依次比较：

1. 较低 E[C|success]。
2. 较低 d，即不以失败概率再归一化的失败 FP 浪费。
3. 较低成功条件 P95，再比较 P90。
4. 较低 MaterialCost，包含成功与失败路径上的实际消耗。
5. 较少声明宏阶段数 L；只允许删除对所有可达入口均已证明无动作的阶段。
6. 前述均相同时，按稳定 ID 与参数构成的规范路线编码排序，保证结果可复现。

P50 作为报告指标，不额外插入用户未约定的首要排序。原生词缀列表顺序属于状态语义，不能为了规范路线编码而重排装备的词缀。

“同分”不能通过显示百分比四舍五入定义。有理数评价使用精确比较；带误差界的数值结果只有区间严格分离时才能证实优劣。区间重叠先提高精度；仍无法区分时保留候选，若需要稳定展示顺序可用编码，但标明排序尚未证明，不能宣称真实同分。

## 6. 证明与报告

非终止质量大于零的路线不作为主推荐。无穷材料／尝试期望作为诊断保留，不截成大数后参与正常评分。

Pareto 候选保留在内部。报告的“最优”只能限定在已完成搜索的动作集、宏语言、阶段上限、材料限制、概率模型和评分约定中。某条路线评价精确，不能替代这些覆盖条件。

首阶段不承诺任意装备和任意目标都能快速完成搜索。性能与搜索限制按[路线搜索契约](route-search.md)报告，不通过改小目标、丢弃概率质量或忽略失败来制造高成功率。
