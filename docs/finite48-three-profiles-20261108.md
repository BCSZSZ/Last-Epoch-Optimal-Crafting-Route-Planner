# 48FP三潜能条件策略（2026-11-08）

从相同初始48FP出发，分别最大化单独希望、冰＋希望、血＋希望的完成率。每个条件均保留结果，概率低于25%显示不推荐，达到25%显示推荐。没有发现概率、无限FP操作成功率、理论FP均值筛选门槛；执行时间／状态预算只影响“本次是否算完”。

## 计算

状态含四个有序普通槽的身份类别、T级、封印及剩余FP。身份分为目标A、目标B、等权非目标；当前普通／封印身份的排除数量保留。等权池中这个合并具有交换性，不把真实异权词缀硬合并。

对每个FP余额逐次计算 `V(s,f)=max_a Σ P(s',r|s,f,a)V(s',r)`。目标状态值1（包括最后一手余0FP达标），未达标且FP0值0；物理失去必要T7来源的值0。费用、制作暴击与词缀变化保持联合分布。免费操作产生同FP循环，消去自环并迭代收敛；区间系数、残差、浮点舍入及低余额误差共同形成后验误差界，不把残差直接当全局误差。

可选动作为补词、升级、绝望封印、混沌、浩劫、救赎、剥离。失手只是新状态，仍合法时可继续选动作；不把封印失败等同于无条件报废。失去T7来源后无法打造回T7，才吸收失败。导出完整可达状态／余额→动作，不将一条成功示例冒充整套策略。

希望25%；冰在希望未免耗时独立免耗30%，合计47.5%。封印用绝望、混沌用混沌，不能同时使用希望，冰自身仍有效。血使合资格碎片制作暴击变成12%＋88%×30%=38.4%；成功封印、浩劫、救赎、剥离不因此暴击，失败封印仍可触发。三套策略各自优化，不能只把普通策略的费用替换成血来评价最优结果。

## 范围与入口

`plan`默认返回`FINITE_48_PROFILES_V3`。`finiteProfiles.profiles`依次NORMAL／ICE／BLOOD，含各自概率界、推荐、首手、实际每件平均耗FP、成功装备平均耗FP、完整条件策略和成功结果示例。`filteringThresholds=null`。25%数值界跨线时保留待确定。

普通100级、可锻造等权普通池、恰好两个普通T7来源和两个不同普通指定T7目标使用完整状态策略，支持已有非目标封印及合法动作限制。保护、实验、异权池、非标准目标等输入沿原子RuleEngine评价固定候选，合并生产程序、结构模板和通用候选，按48FP完成率排名；**仅在当前固定候选范围，不宣称任意条件策略最优**。超预算保留已找到结果并标未完成；未知不填0%。固定候选未计算的实际FP奖励为null，不能借用理论FP均值。

`planLegacy`及显式历史library/seed/intrinsic测试保留原算法；历史文档／报告不重写为新政策。游戏证据版仍为1.5.3；模型指纹因实现变化重建，不冒充新的客户端实测。
