# 三例驱动的求解器试验

用户调整了本阶段目标：先让求解器达到或超过人工方案，通过几轮试验完善；当前阶段不以全装备覆盖或全局最优证明作为验收目标。旧[算法审查](algorithm-coverage-review-20261106.md)保留为问题记录。

本轮三例按7710、7732、7271固定，771x已有正确T7作为验证例。新增独立研究求解器，尚未接入线上Worker。概率仍使用已审计的 `le-1.5.3-iid-b46d3015a01bbdb7`，生产规则和生产生成器保持原版本。

## 做了什么

采用人工示例监督的程序搜索。教师方案用于设定成绩下限；生成模块只接收装备、目标、限制和本轮允许的语法，不读取教师程序或例子名称。

本轮“学习”是依据反例逐轮扩充通用的程序生成规则，再运行搜索和验证，不是拟合概率或训练神经网络。轮次定义由开发者根据示例制定，首个达到训练目标的轮次由脚本自动选择。

基本程序由以下部分组合：

1. 根据目标身份、空槽和前后缀容量，计算最少需要开几个位置。
2. 系统枚举剥离／封印顺序，最多使用一个封印槽。
3. 在开槽前、开槽之间、开槽后分别尝试补入目标；合法空槽分支在规划时固定。
4. 每个封印位置共用同一套直接封印、准备浩劫、接受阶数集合和对象优先级定义。
5. 最后补齐身份并浩劫收尾，整条程序交给联合概率／费用评价。

代码没有7710／7732／7271分支，也不调用旧compileTemplates。接受窗口只定义一次，会进入所有开槽顺序和补词时机。所有运行中的分支均已写入固定程序；没有逐状态重新求最优后缀。

## 人工基线和判定

| 训练例 | 起始情况 | 教师方案 |
|---|---|---|
| 7710 | 前缀T1＋空，后缀T7＋T7；两个新目标前缀 | 添加A → 必要时浩劫将T1放到垃圾 → 封印 → 添加B → 浩劫收尾 |
| 7732 | 前缀T7／T3，后缀T7／T2；目标一前一后，均缺失 | 剥离允许的任一垃圾 → 按空槽补目标 → 封印剩余垃圾 → 补另一目标 → 浩劫收尾 |
| 7271 | 前缀T7／T2，后缀T7／T1；前缀2已有目标，要两个目标前缀T7 | 浩劫至无关前缀1为T1或T2 → 封印前缀1 → 补目标 → 浩劫收尾 |

7732另保存审查中发现的联合窗口方案作为更强下限，防止只追上较弱人工路线就停止。

“达到”沿用当前排序：先通过操作成功率15%、成功路径FP65的门槛；操作成功率较高为优先，同率时成功路径FP较低为优先。48FP整件完成率单独报告。通过此判定不表示每个指标都同时改善，也没有改成最大化48FP完成率。

## 四轮结果

| 轮次 | 通用规则变化 | 达到教师 | 达到最强已知下限 |
|---|---|---:|---:|
| 0 | 固定添加顺序、直接开槽的最小基线 | 0/3 | 0/3 |
| 1 | 加入合法空槽补词和单阶浩劫准备 | 2/3 | 1/3 |
| 2 | 将联合阶数窗口带入所有组合位置 | 3/3 | 3/3 |
| 3 | 扩展非连续阶数集合、低阶对象优先 | 3/3 | 3/3 |

脚本只按训练结果选择首个充分的轮次，选中**第2轮**，再读取验证集。第3轮在三例上增加候选却没有改善成绩，暂不作为选定方案。

第2轮最终结果（普通潜能、匿名胸甲模型）：

| 例子 | 操作成功率 | 成功路径平均FP | 48FP整件完成率 | 当前标签 |
|---|---:|---:|---:|---|
| 7710 | 100.00% | 48.80 | 68.34% | 推荐 |
| 7732 | 42.25% | 64.55 | 20.30% | 不推荐 |
| 7271 | 84.50% | 55.68 | 50.55% | 当前方案 |

7710和7271达到教师方案；7732超过原人工路线的25.065%／57.23FP／14.49%，并达到审查中的42.25%联合窗口方案。7732的FP均值提高了，但仍低于65FP，操作成功率及48FP完成率提高；它依然达不到推荐门槛。

初始7710方案的48FP完成率略高，但操作成功率只有98.14%，按当前操作成功率优先的约定不计达标。这个差异再次说明优化目标需要明确。

## 泛化与化简

固定的24个验证例覆盖前后缀镜像、普通槽顺序交换、7722／7742、已有正确T7的771x、新的T2/T3和T3/T4窗口、身份已齐、普通／冰／血、胸甲／手套／任意参考目录。第2轮在**24/24**例上均未低于教师及保留的更强基线；所有教师都通过当前实用门槛，未跳过失败例。所有生成候选均完成数值评价，无未完成候选。

验证例没有传给生成器，也没有用于选择轮次；这些有限用例不证明任意装备上的最优性。

自动生成的空槽和身份判断会产生冗余控制流，曾使有限FP评价区间偏宽。加入保守的槽位／目标身份分析，删除只能取一个结果的判断和必然跳过的填充，保留每条继续路径上的实际动作。测试逐状态对照化简前后的下一原子动作，遍历所选程序的全部可达随机出口。

化简后第2轮的三个候选数为76、408、13。48FP完成率区间宽度：训练例均低于1e-9，24个验证例最大低于5e-9。化简没有增加新的制作规则或改写概率。

## 下一阶段的范围

当前试验只处理恰好两个普通T7、两个不同普通目标、最少开槽阶段，以及添加／剥离／封印／浩劫。它限定最多两个开槽动作和一个封印槽；并未宣称多次清理、任意升级、救赎／混沌及任意固定程序均已覆盖。

后续以新人工案例逐批扩充目标与独立验证集；每轮保留已学案例作为成绩下限，记录新增规则是否带来实际收益。先沿用本轮达到目标的较小语法，再考虑生产接入。
