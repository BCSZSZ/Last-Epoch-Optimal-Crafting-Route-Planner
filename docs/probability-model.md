# 概率模型与评价精度

状态：Phase 0 数学架构审阅稿，2026-11-03。本文给出计算契约与推导，不是客户端实测结果，也不向游戏规则填入未经核查的概率。

依据：[启动规范第 5–9、11 节](../BOOTSTRAP.md)、[当前原生动作审计](research/affix-actions-audit.md)、[费用与冰血潜能审计](research/forge-fp-audit.md)。游戏参数及执行顺序以两个审计报告和版本化快照为准。

## 1. 随机模型与证据是两条轴

原生实现已经定位，不等于整个客户端随机序列已经被精确复现。游戏 PRNG 给定内部状态后是确定过程；用户没有提供该状态，本工具也不以读取种子为输入要求。

首版概率基准命名为 INDEPENDENT_NATIVE_GRID：各次随机原语的输出视为独立，并保留本地审计证明的离散网格、端点、比较方向及必要的 float32 运算。独立性是公开的数学建模约定，不是对原生 PRNG 完全独立的证明。必须分别记录：

| 字段 | 含义 |
|---|---|
| evidenceStatus | VERIFIED / PARTIALLY_VERIFIED / ESTIMATED / UNKNOWN；描述规则证据 |
| rngModel | 采用的随机原语、网格与独立性约定 |
| evaluationStatus | EXACT_UNDER_MODEL / BOUNDED_NUMERICAL / ESTIMATED |
| searchStatus | COMPLETE / INCOMPLETE；与评价精度独立 |
| optimalityScope | 已证明最优所针对的操作、宏语言、阶段上限与目标范围 |

EXACT_UNDER_MODEL 仅表示在所声明随机模型下用精确枚举、符号或有理数运算求得，不表示逐位复现游戏客户端。使用浮点线性求解时，只有附带有效误差界才能标 BOUNDED_NUMERICAL；仅有小残差不足以声称精确。蒙特卡洛结果标 ESTIMATED，并附样本量、种子及置信区间。

连续均匀近似只可用于明确标注的参考比较。不能把资源中的 float32 参数直接当作有限网格下的严格事件概率，也不能将高 23 位网格模型替代其他不同的整数随机原语。某原语尚未还原时，保留未知或可证区间，不填猜测值。

## 2. 联合原子转移

公开装备状态不包含玩家实际剩余 FP。评价器内部状态为 z=(x,f,k,h,operationLimitState)：x 是完整装备状态，f 是假设剩余 FP，k 是当前宏阶段，h 是该宏有限控制状态；只有显式设置独立操作次数限制时才记录相应 operationLimitState。装备词缀原生顺序、独立封印槽、FP 类型及动作需要的玩家等级上下文均须保留。

所有词缀碎片、符文、雕文固定无限供应，是当前产品统一建模政策，不是用户可填的真实库存。原生“仓储是否还有该碎片”的存在性检查按有货求值；支持物类别、混沌禁暴击和成功封印等其他资格仍按本地代码执行。材料价格、消耗上限及库存余额不进入核的输入或优化目标。独立 maxAttempts 若明确声明则按尝试次数计，不因退款减少，默认未设置。

一个原子动作产生联合核：

~~~text
K_a(z → z', event, fpSpent, diagnostics?)
sum(all joint outcomes) K_a = 1
~~~

event 包含封印是否成功、移除对象、暴击及其他判定所需事实。可选的 debit／refund／recovered 诊断保留材料扣减、本次投入返还与剥离产出，consumed=debit−refund。它们不递减无限供给、不使路线停止，也不参与评分；不能据此去掉与暴击、额外加阶和 FP 退款相同分支中的真实装备后处理。

fpSpent 是本次完整处理后的实际净 FP 消耗。可核对的当前无外源增 FP 操作应满足 fpSpent=f−f'≥0。费用抽样、余额截断、希望／冰保留、暴击退款和低 FP 有序保留都在同一个核内按原生次序执行，不使用“期望费用×平均暴击修正”。展示可同时保留抽样费用、实际扣费和退款，统计使用最终净消耗。

若以后引入真正新增 FP 的操作，必须扩展奖励定义和分布支持；不能继续默认总消耗等于初始 F 减终态 FP。

## 3. 路线事件的判定次序

入口若已满足全部目标，直接成功，空路线无需制作。每个原子动作完整执行后，按以下顺序判定：

1. 剥离失手、必要封印失败、保护约束违背等用户规则产生的 POLICY_ABORT，立即吸收，不执行下一动作。
2. 否则检查完整终局目标；满足即 SUCCESS，包括最后一次操作后 FP 恰好归零的情形。
3. 检查本宏退出条件并推进固定阶段；本宏未退出则保持本阶段。
4. 目标尚未达成且下一动作因 FP、声明的操作次数上限或原生资格无法执行，进入相应失败叶；材料耗尽不属于本产品状态。

因此“目标成功先于 FP 耗尽失败”不能被误读为可以忽略用户指定的剥离／封印失手失败。游戏原生的失败升级及退款等副作用仍先计入失败叶，只是规划器不再补救。

终端分类至少包含 SUCCESS、POLICY_ABORT、RESOURCE_EXHAUSTED、OPERATION_LIMIT、INAPPLICABLE_NEXT_STAGE、ROUTE_EXHAUSTED；其中 RESOURCE_EXHAUSTED 仅表示 FP 耗尽，OPERATION_LIMIT 表示独立声明的制作次数上限。NON_TERMINATING 单列诊断，不能被无声并入普通失败或丢掉质量。

## 4. 宏与整条路线的吸收计算

固定路线及其声明停止规则确定后，所有动作选择已经固定，不在计算中求 max_action。将可达瞬时状态的转移写为 Q，将成功／失败／其他退出写为 A：

~~~text
H = QH + A
(I−Q)H = A
~~~

H 给出每个入口到各类退出的概率。实现求解线性系统，不显式构造逆矩阵。FP 单调不增时，可按 FP 分层；在同一层中，对所有实际零净消耗边求强连通分量并解相应块，不能只消去“装备状态完全相同”的自环。

先识别无通路到出口的闭合强连通分量。它们的质量是非终止质量。若从任何正质量入口可进入此类分量，候选不作为主推荐；返回可定位的循环诊断。计算期望前还要检查奖励：非终止类中的每次尝试总会贡献 attempt，故可达时总尝试期望为无限；某种实际材料消耗只有在该类反复产生正奖励时才必为无限，不能一律认为所有指标均无限。

概率为 1 终止的有限状态吸收模型，方可直接使用上述可逆系统。若数值上无法区分近奇异与真正非终止，返回精度诊断，不以固定迭代次数冒充已收敛。

## 5. FP 消耗、尝试次数与成功条件矩

设 s_i 是从状态 i 最终成功的概率，c_ij 为一次转移的实际 FP 消耗；端点成功的 s=1、失败的 s=0。下列递推由路径奖励相加直接得到：

~~~text
s_i = sum_j p_ij s_j
v_i = sum_j p_ij (c_ij + v_j)          # E[C]
u_i = sum_j p_ij (c_ij s_j + u_j)     # E[C · 1_success]
E[C | success] = u_i / s_i           # s_i > 0
~~~

各 terminal 的剩余奖励为零。将 c 替换为 attempt 或每阶段次数可得到次数期望；材料 consumed、refund、recovered 也可用同样方法求可选诊断，但不构成优化指标。期望可对边上联合结果求和，不能先拆开相关事件再计算成功条件矩。

失败浪费是 E[C·1_failure]；当路线几乎必然终止时，它等于 v−u。条件成功概率为零时，条件均值和条件分位数为 null，界面显示“不适用”，不能显示零。

## 6. 分布表示与尾部

在无外源增 FP、净消耗非负的当前动作集中，给定起始 F 的实际总 FP 消耗支持为 0…F。可以按终态余额直接聚合成功和失败的消耗质量，无需保存完整制作路径。

尝试数与材料消耗因零消耗重复可能有无限支持。接口允许使用吸收核、生成函数或按需 CDF 查询表示，不能要求预先展开全部路径或无限数组。默认输出期望与所需分位数；若提供有限表，另给剩余质量及可证尾界。

截断质量 δ 可约束成功率遗漏，却不能单凭 δ 给无界尝试数的均值误差。条件均值的误差还会受成功概率分母影响，分位数需要通过 CDF 上下界定位。所有截断／近似都保留误差或未分配质量，禁止丢弃后重新归一化伪装精确。

分位数统一定义为左连续逆：Q_p(C)=min{c : P(C≤c)≥p}，p 取 0.50、0.90、0.95。总消耗分布与成功条件消耗分布分别给出；它们都是实际执行消耗，不等于“无限 FP 下达到目标所需预算”。

## 7. 最低数学验证

精确小例用有理数交叉核对吸收概率、成功条件矩和分位数；零成本状态改变环、非终止闭环、失败立即停止、最后一发成功都必须覆盖。实数实现另验证概率质量、非负性、线性残差与误差界；独立蒙特卡洛只作交叉核对，不能替代精确性证明。

[数学夹具](../research/math-fixtures.json) 中的数值全部是明确标注的合成手算例，只验证通用数学与用户停止规则，不能作为 Last Epoch 的概率或材料事实加载进生产快照。可独立运行 python scripts/check_math_fixtures.py；该标准库脚本以 Fraction 重算吸收线性方程、成功条件矩、跨预算混合、离散 CDF 和闭合类奖励，不加载产品引擎。

材料退款夹具仅验证记账，不再代表当前产品有材料目标或费用。新增的真实规则校验必须覆盖两条 7710 路线：直接封印准备与先用浩劫制造 B 侧垃圾 T1 的准备；每次 ADD 的暴击／FP 退款分支继续进入自己的真实阶数和费用核，不能把准备状态收缩成一条确定 7711 路径。
