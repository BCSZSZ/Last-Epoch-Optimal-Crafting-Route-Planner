# 验证计划与证据边界

## 已执行的首阶段检查

本阶段检查安装指纹、数据库完整性、方法字节、提取确定性、研究计算样例和文档／证据链接。最终结果由 [validation.json](../research/validation.json) 记录；不能把这些检查写成生产引擎、浏览器产品或游戏客户端实测通过。

本地重复提取与 `--verify-only` 应逐字节一致。清单内每份数据的 SHA-256 和长度必须正确。跨平台重建不含当前机器绝对路径或临时执行时间，审计日期是固定版本元数据。

## 原子规则矩阵

- 资格：前后缀容量、已有 ID、普通／实验／冠军等类别、各封印槽、底材／职业／等级限制与已腐化状态。
- 浩劫：四普通栏、重复阶数、所有阶数相同、排除当前布局、拒绝抽样保护及 roll。
- 救赎：全部合法崇高逐槽重抽，前槽结果更新后槽候选；不同原生顺序不能被状态规范化合并。
- 混沌：目标按实际制作权重选择，失败身份改变下一次候选；当前版本暴击资格按 Forge 审计，不能套旧研究。
- 封印：成功移槽与失败加阶；必要封印失败后完整结算但后续宏次数为零。
- 剥离：从合法候选均匀选择的数学原语、命中允许集合与失手叶；返还材料单独记账。
- 暴击：主制作槽选择偏置、角色等级、库存资格、免 FP、主材料返还与支持保留。
- FP：0、1、2、3、63；费用大于余额、最后一笔成功、希望／冰保留、血追加检定、低 FP 有序保留、退款。

## 宏、路线与搜索

精确手算小模型与完整枚举为基线；概率质量与终止／失败／成功分布一致。零成本闭环必须求解，不用均值除 FP；不吸收闭环应报告不终止概率和无限期望。

一次宏目标已满足的跳过、运行中成功、必要封印／剥离政策失败、资源耗尽、材料使用限制分别覆盖。完整原生后处理在所有停止判定前执行；政策失败先于偶然满足其他目标，正常目标成功先于 FP=0 的资源失败。

固定宏路线在全部 FP 上相同，改变评分权重只能改变最终选路，不能在路线中插入按剩余 FP 重选动作。默认评分 1–63 等权；失败成本、条件成功均值、零成功 N/A、材料退款及产出有独立手算例。

剪枝与小规模完整搜索对照。完成只证明公开候选语言／宏阶段上限内的最优；预算耗尽不等于证明无解。未支持动作引起的不可达与物理上不可能分开。

## 独立验证与数值精度

资源 float32、原生 PRNG 格点／比较符号、独立连续数学模型分别记录。某个公式已核查不能直接标为客户端位级精确概率。

测试用 Fraction 手算小例，数值版检查概率和、线性系统残差及区间界。独立 Monte Carlo 不得仅从同一待测转移核抽样后自证；使用单独控制流实现和固定种子，事先指定置信区间与样本规模。参考计算器只对齐其版本／假设一致的输入，不作为替代原生证据。

## 浏览器与发布

首次性能检查提前到 Phase 2，完整求解器在 Phase 5 重测。测试 Worker 加载、任务取消／重启、旧结果隔离、模型不匹配、真实词缀池内存与普通／低性能设备。浏览器与 Node 同快照同输入的结果一致。

Pages 用实际仓库子路径检查入口、刷新、Worker、数据与版本。用户不输入实际 FP，计算中编辑不会被旧结果覆盖。线上托管验证不等于游戏客户端制作实测。
