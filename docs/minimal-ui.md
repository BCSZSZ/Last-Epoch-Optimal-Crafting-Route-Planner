# 极简输入与参考模型

2026-11-03，按用户本轮界面约定。运行模型 `le-1.5.3-iid-112b3bf85ebabd0d`。

主页面左侧起始、右侧目标，两栏下方一个“开始规划”按钮，结果在按钮下生成。窄屏顺序为起始、目标、按钮、结果。路线短动作名、统一雕文说明及有证预检见[顺序审阅](acquisition-order-review.md)。移除样例、底材、角色等级、装备等级、空结果宣传及高级参数。23个普通装备部位全部列出；保留普通、冰、血潜能。

起始和详细目标均固定两前缀、两后缀、一个普通封印槽。每槽一排按钮选空／T1–T7，身份可不填。词条下拉框打开后才显示搜索，支持键盘选择；未有中文译名的词条保留原资源英文。

## 目标语义

- 简易目标按前缀／后缀分别设目标数、已有目标数、已有目标T7数。目标最终均为普通槽T7；已有数包含已有T7，不含封印。
- 同侧已有目标位置不唯一时，最多形成四个适用结构，分别计算、说明条件；不只挑有利位置，也不假设自然分布。默认12秒预算在这些结构间分配。
- 详细目标的空槽表示不关心，所选T级为最低阶数，T7恰好为7。身份留空表示该侧任意合法词条。两项任意身份要求仍需两条不同实际词条分别匹配；不锁定同侧第1／第2位置。
- 未指定起始身份按合法普通碎片词条表示，并避开详细目标明确指定的身份。起始明确填同一身份，或简易模式声明已有目标，才算拥有。
- 数量矛盾、错侧、重复身份、不可达T7数量仍报错，不自动放宽。

## 明确的输入模型

按装备已经可锻造处理，内部100级上下文、该部位全职业通用池。原始快照不变，[输入适配](../src/core/input-model.ts)通过`inputModel`选择派生目录：

| 模式 | 使用范围 | 权重与含义 |
|---|---|---|
| `AUDITED` | 原研究、诊断、完整上下文调用 | 原底材／职业／等级及实际权重，核心默认不变 |
| `FORGEABLE_EQUAL` | 简易目标，或有起始占用槽身份未填 | 原正权重候选均等，原零权重及非法候选不被引入；页面标“等权参考” |
| `FORGEABLE_WEIGHTED` | 详细目标且起始占用槽身份全部已填 | 实际制作权重、部位全职业通用池；页面标“实际词条权重 · 通用池” |

这些是输入缺省的简化参考，不是指定实际职业底材的精确池，数值区间也不包含这种模型差异。费用、暴击、封印、剥离、浩劫及NG仍使用同一原子规则。编辑会取消任务并清除旧结果；新`le-crafting-draft-v2`保存键不覆盖旧v1请求。

结果突出操作成功率、最终成功路径平均FP，保留15%／65FP门槛、已算阶段及未完成状态；假设折叠。无需剩余FP或材料库存。
