| 固定停止条件 | 最终命中概率 | 平均救赎次数 | 普通／血成功平均FP | 冰成功平均FP |

上述100%是无FP边界、允许无限继续时的模型终止概率。有限状态链每个状态都能以正概率到达停止集合，因此没有不通往目标的闭类；数值线性方程另核对吸收质量约1。它不是现实单件装备在有限FP内的成功率。

“任一目标命中”首次停止时：仅A为48.24540055%，仅B为48.24540055%，AB同时齐为3.50919890%。

“指定A命中”首次停止时：仅A为93.77474179%，AB齐为6.22525821%。A／B制作权重均为1，交换两目标的全部统计对称。**第一阶段只花约26.37或50.97FP，不代表补齐第二个目标的整条路线也低于100**；后续路线需与终态联合计算。

结构化结果的`gloveFixture.targetA.terminalOrderedWeightGroupDistribution`保留每个出口的原生两槽顺序、命中目标ID、另一词缀的权重类别、一个真实代表ID、概率`p_exit`、次数第一矩`E[N·1_exit]`以及普通／冰FP第一矩。`atLeastOne`同样保留完整出口。类别中的具体非目标ID没有逐一分解；对只依赖A／B身份和其他词缀权重的后续核，这些ID可交换。若后续约束区分组内具体ID，须进一步细分。

## 单次FP费用与联合首矩

救赎费用先在1–19等权抽X；以28.5%几率重新在`[1,X)`抽，X=1时仍为1。希望25%免FP，未免时冰另判30%；纯符文没有普通／血制作暴击。无初始余额边界的需求核不触发“剩余FP不足时保留1／2”的兜底。[Forge原生费用和顺序](forge-fp-audit.md)

```text
E[基础费用含幸运] = 8.5825
E[救赎＋希望，普通／血] = 8.5825 × 0.75 = 6.436875
E[救赎＋希望，冰] = 6.436875 × 0.7 = 4.5058125
```

在声明的独立抽样模型里，纯救赎的身份变化与这一费用核独立，且无制作暴击退款；因此某出口的FP第一矩是该出口次数第一矩乘单次费用均值。本结论只用于这条纯符文前缀，不推广到普通制作的暴击／费用关联。

## 能否全局删除“双救赎命中”路线

本次在38个普通底材／职业池组分别选择制作权重最高的目标，扫描双T7前缀、双T7后缀及一前一后，共114种纯救赎案例。每例另求所有合法非目标起点中的最好／最差期望。混合侧别案例固定每侧一个最高权重非目标低阶ID；其完整条件记录在JSON。这是在寻找反例，**不是穷举所有目标对或全部混合路线的最优性证明**。

最低的已扫描普通／血需求为100.034701FP，略超100；冰有一个明确的低于100反例：

| 项目 | 内容 |
|---|---|
| 装备 | 靴子，type3／classRequirement0；例如底材`3:0` |
| 起始两个T7前缀 | ID502智力、ID504协调；其余两条可为普通非目标后缀7／10 |
| 目标T7前缀 | ID28移动速度＋ID501力量，制作权重均1 |
| 前缀候选池 | 7个ID，总制作权重约6.20000005 |
| 固定路线 | 救赎＋希望，直到两目标同时为T7 |
| 成功率／次数 | 无FP边界最终100%，平均15.54087989次 |
| 普通／血需求 | 100.03470127FP |
| **冰需求** | **70.02429089FP** |

所以以“最终成功率至少15%、成功平均需求不高于100”为准，**不能称所有双救赎路线都必然越阈**。用户可以将它整体排除作为明确的策略范围偏好，但不宜描述为已证明全局劣势或全部不合阈值。若按具体底材／目标参数判断，手套的直接双救赎可以过滤；靴子的上述冰例可以保留。

另有可直接判纯救赎不可达的结构条件：两条T7均为后缀，A／B却都是前缀且起点没有目标T7。救赎保阶、保前后缀侧别；仅反复救赎无法将前缀变T7。JSON给出固定手套反例，最终概率0、永不完成。此结论只限制纯救赎，不排除浩劫等其他动作。

## 压缩链和复核

### 单发双中可安全过滤，与重复宏分开

在当前38个合格装备／职业池组、76个侧别候选池中，所有正制作权重均不大于1。最低侧别总权重为靴子前缀的`W=6.200000047683716`；前缀最小值同此，后缀最小值为`8.539999723434448`。范围是四个Standard普通词缀、没有额外封印词缀的物品。[原始权重和资格](../../data/game/1.5.3/affixes.json)、[逐池算术结果](../../research/redemption-intrinsic.json)

两条T7同侧时，每次分母至多排除该侧两个ID，每个权重不超过1，因此分母至少`W−2`。目标A／B均不在起点，单发双中包含AB／BA两个顺序，所以全体上界为`2/(minW−2)^2 = 11.3378682233%`。两T7分在前后缀时，上界为`1/((minW前−2)(minW后−2)) = 3.6406000835%`。脚本以Fraction验证两者均严格小于15%；靴子起始502／504、目标28／501的一发概率恰好达到前一个界。

所以，在上述声明的独立归一化模型和物品范围内，**只用一发救赎、必须同时双中的整条路线可以按15%门槛安全过滤**。反复救赎直到双中是不同宏，其最终概率可为1，靴子冰需求约70.02FP的反例仍成立。不要把这个单发界用到含额外封印排除、其他后续动作或重复宏的整条成功率上。

目标A／B各占独立类别，其余ID按同侧、相同制作权重合并。状态是当前两个T7的**有序类别对**。第一槽抽类别g的权重为：

```text
(count_g - 1[currentFirst in g] - 1[currentSecond in g]) × weight_g
```

第一槽更新后，第二槽按新的第一槽类别和自身旧类别重新排除。组内同权重非目标ID可交换，类别计数足以保留这个完整两槽重抽核。不能在第一槽暂时凑齐目标时停止。[同侧候选、已有ID排除及逐槽写回证据](affix-actions-audit.md)

对暂态核Q、各终态的直接命中列R：

```text
(I-Q) t = 1             # 平均次数
(I-Q) B = R             # 各出口概率
(I-Q) M = B             # 各出口次数第一矩
```

脚本用Python标准库的带主元线性方程求解，不依赖NumPy。手套完整有19×18=342个有序具体ID状态，压缩后33状态。另用独立具体ID逐槽展开核对全部342行，压缩前后最大转移差约1.78×10⁻¹⁵；不等同于通过重复同一压缩实现验证自身。四ID等权小模型以Fraction求解，双中／任一／指定A的期望分别为15/4、1、4/3，均与压缩求解一致。费用均值以Fraction计算；各终态概率和、次数第一矩和、方程残差及A／B对称性另作检查。[研究脚本](../../scripts/research_redemption_intrinsic.py)
