# 单件装备的优化目标与评分

> 当前政策（2026-11-08）：初始48FP内完成率为主指标；单独希望／冰＋希望／血＋希望分别求解，低于25%不推荐、达到25%推荐，没有旧15%或65FP过滤。普通等权双T7采用状态条件策略，非标准输入明确固定候选范围。见[当前算法与验收](finite48-three-profiles-20261108.md)。下文保留早期设计／测量记录。

**当前生产指标（2026-11-04）**：[操作成功率＋成功路径FP期望](metric-revision-2026-11-03.md)使用15%／65FP门槛；候选通过后仍先比较操作成功率，同分再比较成功路径平均FP。新增[起始48FP整件完成率](completion48.md)，低于25%标不推荐、高于65%标推荐，等号中性，区间跨阈保留待定。下文为旧有限FP主评分基线，不作为新增48指标的计算方法。

状态：Phase 0 数学架构审阅稿，2026-11-03。遵循[启动规范第 6–8 节](../BOOTSTRAP.md)及用户确认的等权预算、固定宏路线与失手即停止约定。本文的权重和排序是产品定义，不是游戏掉落事实。

## 1. 评价对象和预算

只优化当前给定的一件装备。起始底材、词缀与 FP 类型固定；不包含购买替代品、失败后换底材重新开始，也不把不同 FP 类型当成可自由转换。

公开输入没有玩家实际剩余 FP。评价器内部按 D={1,…,B} 分别模拟假设预算；当前版本的 setter、生成／赋能路径和序列化审计确认持久化普通装备 B=63，故默认域为 1…63，见[打造审计](research/forge-fp-audit.md)。未来版本仍由对应快照给出 B，不能从 byte 字段宽度推断。F=0 单独给边界结果，不进入默认评分。

默认 w(F)=1/B。高级配置可以指定有穷预算域与非负权重，必须至少有一项正权重并在评价前归一化；所有路线共享同一输入和同一权重配置。结果原样列出预算域和权重，既不猜玩家真实 FP，也不宣称它们代表自然掉落分布。

## 2. 首要评分

令 S 表示该单件按固定路线 R 执行后成功，P_R(F)=P(S|R,F)。

~~~text
J(R) = sum_F w(F) P_R(F)
~~~

J 是假设预算混合下的完成概率。先选择同一个 R，再对所有 F 求值。不得先为每个 F 或每个随机中间状态分别取最优，再把所得包络当成一条可执行路线。

已满足目标的起点可返回空路线，所有预算下成功率为 1、消耗与阶段数为 0。无可行路线、输入本身不合法、所限语言内已证明不可达、搜索未完成但尚未找到路线，必须用不同状态表达。

## 3. 统计口径

对于预算 F，记录实际净 FP 消耗 C_F、制作尝试数 A_F 及 S 的联合分布。材料计数仅可作为诊断，不是优化坐标。

~~~text
p_F = P(S | F)
m_F = E[C_F | F]
u_F = E[C_F · 1_S | F]
d_F = E[C_F · 1_failure | F]

p = J(R)
m = sum_F w(F) m_F
u = sum_F w(F) u_F
d = sum_F w(F) d_F

E[C | success] = u / p              # p > 0
E[C | failure] = d / (1−p)          # p < 1
~~~

成功条件混合均值必须用 u/p。将各预算的成功条件均值直接按原始 w 平均，会忽略“成功样本中的预算构成”已经被 p_F 改变。

总消耗 C 的 CDF 为 sum_F w(F)P(C_F≤c|F)；成功条件 CDF 为 sum_F w(F)P(C_F≤c,S|F)/p。二者均报告 P50／P90／P95。没有成功样本时成功条件指标为 null；不能用 0 表示。

实际净 FP 消耗包含最终未完成路线已花费的 FP；不是“每次失败换装备直到成功”的多件成本。尝试数按完整制作计数，不因 critical 返还材料而减少。材料扣减、退款及产出只可作可选诊断；它们与暴击／FP 退款共享的原生分支仍完整保留。

## 4. 固定无限物料与诊断

所有词缀碎片、符文和雕文固定无限供应。没有材料价格、库存或材料消耗预算输入，也没有 MaterialCost 项。材料数量不影响候选合法性、主评分、Pareto 轴或任何同分比较；不以尝试次数代替已取消的材料代价。

支持物种类、符文种类及其原生资格仍决定状态转移；无限物料不等于取消希望／绝望的差别，也不等于可同时装入不兼容雕文。原生仓储存在性检查在此固定供应模型下按有货求值。

若保留研究诊断，分别记录 debit、refund、consumed=debit−refund 和 recovered；critical 返还本次投入、保留雕文和剥离产出等已审事实不删除。它们不需要递减供给或折算费用。生产报告可以省略这些诊断，尝试次数仍按宏契约报告。

只有显式声明的独立操作次数限制会约束重试；默认不设。该约束不同于搜索时间／节点预算，后者使搜索 INCOMPLETE，不改变某一候选的制作概率。

## 5. 确定性词典序

在主评分无法区分后依次比较：

1. 较低 E[C|success]。
2. 较低 d，即不以失败概率再归一化的失败 FP 浪费。
3. 较低成功条件 P95，再比较 P90。
4. 较少声明宏阶段数 L；只允许删除对所有可达入口均已证明无动作的阶段。
5. 前述均相同时，按稳定 ID 与参数构成的规范路线编码排序，保证结果可复现。

P50 作为报告指标，不额外插入用户未约定的首要排序。原生词缀列表顺序属于状态语义，不能为了规范路线编码而重排装备的词缀。

“同分”不能通过显示百分比四舍五入定义。有理数评价使用精确比较；带误差界的数值结果只有区间严格分离时才能证实优劣。区间重叠先提高精度；仍无法区分时保留候选，若需要稳定展示顺序可用编码，但标明排序尚未证明，不能宣称真实同分。

## 6. 证明与报告

非终止质量大于零的路线不作为主推荐。无穷尝试及可选材料期望作为诊断保留；材料诊断不参与正常评分。

Pareto 候选保留在内部。报告的“最优”只能限定在已完成搜索的动作集、宏语言、阶段上限、独立操作限制、概率模型和评分约定中，供应政策固定为无限。某条路线评价精确，不能替代这些覆盖条件。

首阶段不承诺任意装备和任意目标都能快速完成搜索。性能与搜索限制按[路线搜索契约](route-search.md)报告，不通过改小目标、丢弃概率质量或忽略失败来制造高成功率。

7710 两条指定路线比较时，准备浩劫即使消耗更多符文，也不能因此扣分；它是否值得采用只由完整成功率、FP 分布及后续固定同分规则决定。每次添加后的暴击分支和额外准备的失败质量均进入相同口径，不只比较单发最终浩劫概率。
