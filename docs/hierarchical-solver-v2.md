# 23节点求解器：细分结构、完整模板与剪枝契约

2026-11-03。已进入生产求解逻辑；[早期分层论证](strategy-hierarchy-design.md)继续解释为何不能仅按数量合并概率。主指标为操作成功率P(S)和成功路径平均FP E[C|S]，物料无限。FP持续充足，不读取起始余额，不套接近耗尽时保留1／2FP的边界福利。

## 分类与细分结构

范围是两个不同的Standard普通目标A／B各T7、无roll目标、恰好两个普通未封印T7。28个G/N/S标签中，220六个标签合并到DONE，成为23个路由节点。N只数普通未封印栏，S只数普通封印占用。T8／腐化等额外槽独立保留。三个／四个普通T7、替代目标、封印目标及roll要求使用明确标注的通用候选路径，不硬塞进六类。

每个节点按以下正交维度细分，没有用几个阶数例子代替整片范围：

| 维度 | 完整划分与用途 |
|---|---|
| 普通空位 | N2时(空前,空后)为(2,0)/(1,1)/(0,2)；N3为(1,0)/(0,1)；N4为(0,0) |
| 目标角色 | A/B前后缀四种配置；已取得身份mask；211/210/201区分当前已有的是A还是B |
| 阶数 | 每个对象实际T1…T7；非T7相等／不同；T1…T4的可封资格、T1…T4混沌窗口、T5、会参与救赎的T6分别保留 |
| 身份与顺序 | 全部实际ID及原生列表顺序；不能按垃圾角色或显示顺序替换救赎排除集合 |
| 封印与额外槽 | 普通封印ID、其他额外ID；占用不等于ID可忽略，缺失普通目标被固定额外槽占用时提前报告不可达 |
| 资格上下文 | 底材、职业、玩家等级、碎片资格、特殊类别、保护、禁用动作、显式次数限制、模型版本 |

这些字段决定叶子结构。宏只读取它需要的字段，但当前数值缓存采用完整实际装备键，保持原生顺序；没有无证明地将232个投影标签当成精确DP状态。

## 逐个节点的模板规则

下表中的“取得缺失身份”展开为后文的全部方法族；“收尾”表示必要时补满普通栏，再重复浩劫至A/B各T7。每条完整模板最后都使用同一个目标判断，途中达标立即停止。

| 路由节点 | 需要细分的结构 | 生成的完整策略骨架 |
|---|---|---|
| DONE | 220、N2/3/4、S0/1共六个入口 | 直接成功；FP=0，不补空栏 |
| 211-N3-S0 | 唯一空位侧别、填充资格、非T7阶数 | 填充→收尾；不额外封印 |
| 211-N3-S1 | 同上，加封印ID排除填充 | 填充→收尾 |
| 211-N4-S0 | 两个非T7同阶／异阶、保护 | 直接收尾 |
| 211-N4-S1 | 同上；封印不进入普通浩劫排列 | 直接收尾 |
| 202-N4-S0 | A/B实际tier、两个非T7重复阶数 | 直接收尾 |
| 202-N4-S1 | 同上；额外槽保持 | 直接收尾 |
| 210-N2-S0 | 两空位侧别、缺失目标侧别 | 可直接补则补→填充→收尾；否则填充→准备／腾位或换词→收尾 |
| 210-N2-S1 | 同上、封印ID | 相同方法排除再次封印，保留剥离／混沌／救赎 |
| 210-N3-S0 | 唯一空位能否容纳缺失目标 | 直接补或填充后准备腾位；取得缺失身份→收尾 |
| 210-N3-S1 | 同上、普通封印已占用 | 直接补或剥离／混沌／救赎；需要浩劫时先补满 |
| 210-N4-S0 | 目标侧垃圾tier／资格、已有目标T7是否参与救赎 | 各腾位／换词模板，必要时先浩劫；最后收尾 |
| 210-N4-S1 | 同上，加固定封印排除 | 禁再次封印，其他身份来源逐一检查 |
| 201-N3-S0 | 空位侧别；已有目标T1…T5或T6 | 补词或准备腾位；救赎显式区分已有目标是否被重抽 |
| 201-N3-S1 | 同上、封印ID | 禁再次封印；其余同上 |
| 201-N4-S0 | 已有目标的低阶不能当垃圾；垃圾tier与资格 | 封印／剥离／混沌／救赎取得另一个身份→收尾 |
| 201-N4-S1 | 同上、目标被固定槽占用的边界 | 排除封印，保留其他完整模板 |
| 200-N2-S0 | 两目标侧别和两个空位的匹配 | 两种添加顺序；只能先补一个时，补一个→填充／腾位→另一个；必要时先填垃圾再浩劫 |
| 200-N2-S1 | 同上、封印不可再用 | 两种添加顺序及剥离／混沌／救赎组合 |
| 200-N3-S0 | 空位可容纳A/B哪一个；原垃圾T1…T6 | 先补可放目标→准备／封印／剥离／换词→补另一目标；覆盖7710的暴击T1保护 |
| 200-N3-S1 | 同上，不能再封 | 补词后剥离或身份重抽；也保留先开位置的组合 |
| 200-N4-S0 | 两目标侧别、两条非T7垃圾的位置／tier | 先开两个位置再补；开一个就补后再开；混沌／救赎及明确混合模板 |
| 200-N4-S1 | 同上，唯一封印已经占用 | 双剥离先开两槽、剥离与补词交错、混沌／救赎和准备；不误用二次封印 |

## 固定模板语法及停止条件

每次请求只编译实际入口的模板，不搜索任意宏排列。缺一个身份时组合一次取得模块；缺两个时组合两次取得模块并比较A/B两种顺序，另外加入批量腾位、先中任意目标及多阶段救赎族。

| 方法族 | 固定行为 | 退出／NG |
|---|---|---|
| 直接添加 | 缺失ID有合法侧空位时添加；已有身份则按声明跳过 | 不合法即该模板失败，不覆盖已有ID |
| 直接封印 | 目标侧非目标垃圾，分别生成T1/T2/T3/T4对象条件 | 封一次；未封印立即NG |
| 准备封印 | 补满→浩劫至声明tier的合侧可封垃圾→封一次→添加 | 准备子目标不可达时该模板无成功出口；不得自动升阶后重封 |
| 直接／准备剥离 | 允许集合排除A/B及保护对象，只接受可剥且非T7的垃圾；需要时先补满／浩劫搬阶 | 失手完整结算后NG；移走必要T7的分支不被保留 |
| 先开两槽 | 双剥离、封后剥、剥后封，再添加A/B；含必要的预先搬阶 | 和“剥→加→剥→加”分开计算；后者第二次有新误剥对象 |
| 混沌有限窗口 | 对固定侧合法垃圾按原生顺序选择，升至T5前寻找身份 | 窗口耗尽默认NG；不把原生未破坏装备解释为一定要NG |
| 混沌恢复／补救 | 允许浩劫将剩余低阶搬回该侧；或窗口耗尽后进入预先声明的封印／剥离／救赎后缀 | 每次混沌总tier上升，窗口有限；无下一窗口才走声明的退出。没有临时重新搜索 |
| 单发救赎 | 仅一发完整救赎，身份齐全后收尾 | 未取得所需身份不能靠最终浩劫补身份，单独评价后按阈值放弃 |
| 重复救赎双中 | 完整重抽所有普通T6/T7后检查两个目标身份 | 不是按首发命中率套几何分布；允许多发，按具体FP阈值判断 |
| 救赎先中一个 | 重复至A或B命中；预先声明“有A补B、否则补A”分支 | 若双中已达标直接停；各分支所用后缀在规划前固定 |
| 两阶段救赎 | 先得A→填充／浩劫使A≤T5、B侧仍有可重抽垃圾→再得B→收尾；比较A/B顺序 | A=T6仍会被救赎，不能当成已保护身份 |

填充采用预先声明的合法碎片ID顺序：每次取第一个当前可加的非目标ID，结算暴击及额外加阶。这是可审阅的模板范围，不是所有垃圾ID已证明等价，也没有宣称遍历全部填充ID的全局最优。身份齐全时当前模板采用直接收尾基线，不扩展任意额外升阶／roll控制器。

## 数值评价和复用

`RuleEngine.demandTransition`复用同一套原生操作后处理，投影为每个出口的概率K和费用首矩R=E[C·1出口]。费用投影使用63缓冲，仅为避免单次扣费截断，不携带FP余额；暴击退款和状态变化仍联合。严禁把独立平均费用乘进另一份状态分布。

有限程序节点为(固定程序位置、完整装备、可选剩余操作次数)，没有旧F0…63轴。固定分支编译为程序位置；随机出口不重新选择最优后缀。联合矩满足：

```text
p(i) = Σ K(i,j) p(j)
m(i) = Σ [K(i,j) m(j) + R(i,j) p(j)]
E[C | S] = m(起点) / p(起点)
```

浩劫先枚举6／12等有限布局，使用已证排除原布局对称性求完整退出核。救赎保留动态池和原生逐槽更新，构造有状态吸收链。数值迭代后，以向外舍入验证h≥1+Qh，再用Bellman残差乘h包围概率及费用误差；不能以“迭代看起来收敛”冒充精确。

没有NG出口、且每个节点都有正概率路径到成功的有限链可证明P=1。对此类昂贵重复救赎，可用有限轮奖励迭代给出费用下界；下界超过65即停止，无需先算出900FP等完整均值。免费但会退出的循环与闭合不终止类分别检查。

单次请求共享原子联合核和完整路线结果缓存，键包含真实ID／tier／原生顺序和固定请求上下文。跨底材、版本或保护条件不共享。没有把不同无关阶数的211合并成同一浩劫数值。

## 剪枝规则及证明范围

1. 输入必要条件：目标／槽容量、不可制作状态、等级、ID冲突、必要T7数量；缺失普通目标已在固定额外槽占用时直接报告。
2. 明确范围：禁用动作按嵌套分支递归检查；超出用户宏阶段限制的模板不进入本次范围。
3. 起点资格：仅在实际初始状态证明第一步不可用时删除；不会据此删除先填充／浩劫准备再操作的另一条模板。
4. 准备可达性：第一浩劫宏的全部布局均不能满足子目标时删除；第一救赎宏没有对应侧／tier的可重抽来源时删除。此判断不跨越随机前缀猜测未来状态。
5. 唯一封印：两个初始缺失身份分别由必需封印＋添加取得、且前一模块不可能顺带取得另一身份时，两次封印组合必失败，直接不生成。存在混沌／救赎身份分支时不套这条证明。
6. 同一路线JSON去重，不基于三位类别码合并概率。相同保留路线的Pareto比较使用数值界。
7. NG前缀：前缀过关概率上界<15%时停，后续宏不展开；报告前缀概率口径及已算阶段。恰好15%不删。
8. 成功条件费用：先保留最终成功事件，再逐阶段累计相应费用首矩；累计下界/P上界>65时停。不能按前缀过关均值>65直接砍。
9. 全成功重复链：使用上述有限轮奖励下界；保留未算全的均值为null，只报告“≥下界”，不把下界当完整平均数。恰好65不删。
10. 时间、节点、转移数量、单模板计算预算不足或数值界跨阈值：UNRESOLVED／INCOMPLETE，不能标“已放弃”或“游戏无解”。

模板调度先覆盖常见T1准备、直接补词、批量腾位及救赎／混沌代表，再比较深层变体。默认复杂混沌单模板最多300ms，其余最多1500ms，同时受整次12s限制；这些是执行预算，不是游戏操作次数上限。未算完模板保留在未完成计数中，不转成NG。

## 报告与验收

`PlanReport.metric=INTRINSIC_V2`。主推荐只取已确认通过门槛的完整模板；`abandoned`保留路线、已算阶段、概率／FP口径和原因；`unresolvedRoutes`单列。FP下界另存`successfulFpLowerBound`，完整均值未算完时`expectedFpGivenSuccess=null`。旧有限FP曲线、分位数及旧逐宏统计数组不再冒充新指标；辅助总／失败费用仅在`auxiliaryTotalsAvailable=true`时有效。

覆盖、有限语法穷尽、范围内最优和全游戏最优分别陈述。当前不因标签覆盖或若干性能案例就宣布全局最优；默认48候选可能未覆盖所有已编译模板。
