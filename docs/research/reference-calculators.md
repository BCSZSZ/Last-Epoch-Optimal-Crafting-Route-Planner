# 公开参考计算器交叉核对

2026-11-03实际读取Tunklab公开表，并在浏览器操作计算器。来源主页标注数据版本1.5.2；只对照本地1.5.3原生代码已确认相同的公式，不替代当前游戏代码。记录见[冻结观察值](../../research/reference-calculators.json)，产品回归见`src/core/external-references.test.ts`。

- [封印表](https://lastepoch.tunklab.com/seal-chance)：普通／崇高各4阶×4词缀数，共32格。其105%是未饱和阈值，本地Roll在阈值至少1时直接成功，事件概率以100%比较。
- [FP费用计算器](https://lastepoch.tunklab.com/fp-chance)：固定三词缀、T1→T2升级、希望，分别选择普通／冰／血；逐格核对0–9FP的PMF及CDF、平均费用和暴击率。产品核入口取63FP，避免低FP有序保留干扰。这不验证低余额或绝望的联合分支。
- [浩劫计算器](https://lastepoch.tunklab.com/havoc)：实际配置1177、3277、3777，目标两个前缀均T7；显示20.00%、18.18%、66.67%。同时核对高FP下的单发平均费用。其平均次数及达标费用是无限预算参考，不能代替产品有限FP的完整路线统计。

外部显示值已舍入；测试以对应显示精度的半个末位单位为容差，不把18.18%当成原生精确分数。比较范围、参数及版本保留在数据中，不能据此把整套求解器标成“第三方计算器全量验证通过”。
