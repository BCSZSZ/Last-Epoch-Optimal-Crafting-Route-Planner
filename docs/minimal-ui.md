# 极简输入与参考模型

2026-11-05。当前模型 `le-1.5.3-iid-591a4fa7a4d6e547`。

主页面左侧起始、右侧目标，两栏下方一个“开始规划”按钮，结果在按钮下生成。部位首项为“任意”，新输入默认选中；其余23个普通装备部位全部列出。保留普通、冰、血潜能。移除样例、底材、等级与高级参数。

起始和详细目标固定两前缀、两后缀、一个封印槽。每槽使用空／1–7按钮，不显示T前缀。词条可留空，下拉框展开后可搜索，支持键盘选择。简易目标模式在四个普通槽提供“已是目标词缀”复选框；空槽不能勾选，封印不计普通目标。

## 目标和保存

- 简易模式右侧只编辑“前缀目标T7数”“后缀目标T7数”。已有目标词条数、已有目标T7数从左侧勾选和阶数派生，以只读数字显示。
- 勾选确定具体位置，同侧同阶词缀不再生成位置猜测分支。勾选时最终目标数至少包含勾选对象；取消勾选保留最终目标数，表示仍需补齐。改阶数更新已有T7数，清空槽位清除勾选。默认12秒用于一个明确输入。
- 详细目标保持原语义：空槽不关心，所选阶数为最低阶，7恰好为7；身份留空为该侧任意合法词条。多项要求分别匹配不同词条，不锁第1／第2位置。具体ID匹配拥有状态，左侧勾选用于简易模式。
- 非法身份、错侧、重复ID、不可达阶数及数量矛盾明确报错，不自动放宽。编辑取消任务并清除旧结果。

保存格式升级v3，沿用`le-crafting-draft-v2`键；首次迁移前将完整原文备份到`le-crafting-draft-v2.before-v3`，不覆盖已有备份或v1请求。原部位、阶数、具体身份和目标数保留。旧已有数量唯一对应某个槽位时自动勾选；位置有歧义或数量与起始槽矛盾时，保留原数量并提示左侧确认，确认前不计算，不静默挑选位置。

## 输入参考模型

按装备可锻造、内部角色／物品等级100处理。原始游戏快照不变，[输入适配](../src/core/input-model.ts)选择派生目录：

| 模式 | 使用范围 | 概率口径 |
|---|---|---|
| `AUDITED` | 原研究、诊断、完整上下文 | 原底材／职业／等级及实际权重 |
| `FORGEABLE_EQUAL` | 已指定部位的简易目标，或有起始身份未填 | 该部位全职业池，正权重候选等权，原零权重不引入 |
| `FORGEABLE_WEIGHTED` | 已指定部位、详细目标且起始身份全填 | 实际制作权重、部位全职业通用池 |
| `FORGEABLE_ANY_EQUAL` | 任意／未指定部位 | 普通装备合法候选并集，正权重候选等权；明确使用虚拟参考底材，不暗选某个真实部位 |

“任意”页面标通用等权参考，它不是全装备或真实掉落的平均值。救赎、混沌依赖词条池时有模型差异；指定部位后切换对应池。互不兼容的具体词条即使在任意模式也拒绝。数值区间不包含参考模型与实际装备池的差异；费用、暴击、封印、剥离、浩劫和NG结算保持同一原子规则。

结果保留成功率、起始48FP的整件完成率与最终成功路径平均FP，15%／65FP放弃门槛不变。整件率低于25%不推荐、高于65%推荐，等号中性。[计算契约](completion48.md)、[路线顺序](acquisition-order-review.md)。

## 验证

155项TypeScript回归、30项Python回归、112例分层对照通过。当前输入测试18项覆盖精确归属、只读计数、改阶／清空、v2唯一／歧义迁移、任意部位生产规划、并集权重、非法具体词条和快照不变。

[三份本地静态页面／Worker导出](../research/ui-validation/slot-targets-local-parity.json)与Node完整主报告及48FP结果逐位一致：任意7710为100%／68.34%／48.80FP；任意及指定手套7721为100%／72.26%／44.61FP。实际检查了勾选、只读统计、改阶、清空、刷新保留、可选词条搜索与选择、390px视口无横向溢出。先前UI记录按[原模型归档](../research/runtime-model-archive/manifest.json)重放，不作为本轮UI证据。

这些验证不冒充游戏客户端实测或物理手机性能；低性能实机按用户约定继续待验收。[预计算设计](precomputation-plan.md)。
