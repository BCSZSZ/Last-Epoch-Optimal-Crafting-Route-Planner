## 本次 7710 算法模型校验

先固定原生证据、底材和实际词缀 ID，分别建立：

1. 侧别合适的 ADD(A)→SEAL(垃圾)→ADD(B)→HAVOC(A／B 普通栏各 T7)。
2. 侧别不合的 ADD(A)→准备 HAVOC(B 所需侧有可封垃圾 T1)→SEAL(该侧垃圾)→ADD(B)→最终 HAVOC。

封印 selector 按已声明 side／垃圾／可封／tier 条件过滤，随后取最低原生列表序号。准备 HAVOC 与最终 HAVOC 使用不同局部谓词；无须预设 B 已存在才能生成准备宏。每次添加的暴击、额外升阶、FP 退款及低 FP 保留分支都继续进入自己的完整状态，不统一成 7711。一次必要封印失败立即停止。

对 F=0…63 给出路线评价；主评分仍只用 1…63 等权。分别核对总成功质量、失败分类、实际 FP 均值／条件均值／分位数和尝试数，覆盖普通／冰／血模型。独立计算或采样与吸收求解对照时说明随机模型和误差，不把模型结果称客户端实测。

此校验用于证明模型能表达和计算用户提出的路线，不等于完成全候选搜索，也不预先宣布两条路线最优。无限材料条件下比较只按成功率和既定 FP／宏阶段 tie，准备宏用了更多浩劫不构成惩罚。

## 已有 A 的 771x 与通用覆盖

补充用户最常见模式：四普通栏 771x、已有 A@T7、缺 B。x=1…7 分别固定实际状态，包含 x=7 的三个 T7 边界，不把 x 视为未知并复用同一概率。直接路线为 SEAL(合侧垃圾 T1)→ADD_B→FINAL_HAVOC；错侧时先 PREP_HAVOC 使 B 侧出现可封的非 A／B 垃圾 T1。

已有 A 不再 ADD_A，本模式的封印／移除选择器排除 A，允许准备浩劫暂时移动 A 的 T7。该候选的保留方式不自动成为全局硬保护；仅按用户明确设置的身份、tier／roll保护限制其他路线。最终仍要求 A、B 位于普通未封印栏且各恰好 T7；添加 B 的暴击、FP 退款及后续真实状态完整传递。

x=0 是三普通栏；SEAL→ADD_B 后仍为三栏，须额外补栏才能浩劫。若 B 可直接放入原空栏，也保留直接 ADD_B→FINAL_HAVOC 的合法候选。概念、侧别和资格边界集中记录在[常见打造模式](examples/common-crafting-patterns.md)，模型数表与结果链接按实际完成状态追加。

常见模式只决定候选优先展开及回归基线，不限定全局搜索。7732 两目标都缺等更复杂起点可涉及救赎、封印、混沌及其合法组合，尚未系统评价时标 UNASSESSED，搜索未完成时标 INCOMPLETE。只有明确范围内的不可达证明才能给不可达结论，不能因人脑未评估、缺少 T1 模板或尚无结果而判 IMPOSSIBLE。

在此之前先判身份齐全：7732 中若 A／B 正在 T3／T2，只需优先评价 FINAL_HAVOC 基线；“两条 T7 非目标”不等于所有身份都缺。复杂身份搜索的案例必须明确四个实际 ID 均非 A／B，不能仅靠同一阶数字串归类。

## 执行接口与浏览器可行性

React 管理输入和展示，求解器不依赖 React／DOM／Worker。首版只有浏览器执行 Adapter；需要服务端时再实现相同契约的 Node Adapter，不预先建设多套服务器。

Worker 数据加载一次，进度／结果只发送摘要；大分布留在计算模块。测量真实词缀池的双 T7 重排、稀有救赎、封印／剥离前置、三类 FP，以及复杂目标。记录时间、峰值内存、搜索规模、取消响应、结果版本和评价精度。普通电脑与低性能设备分别报告，不用玩具性能承诺真实全搜索速度。

搜索预算与内存限制公开；未完成不冒充全局最优。发现热点先改状态表示、重复计算和可证明剪枝，必要时评估局部 WebAssembly，不能通过悄悄删目标或尾部概率达标。

当前接口不建设物理库存、材料报价和消耗预算。支持物类别仍是动作参数，可选诊断保留原生退款／产出；独立操作次数限制如显式使用则进入模型 scope，与计算预算分开，网页不强制显示。

## 托管顺序与已授权公开

1. 默认当前仓库直接发布 GitHub Pages。Vite 设置仓库子路径，打包 Worker 和数据，发布完整同版本静态产物。
2. 部署时核对账户资格。若私有仓库不支持 Pages，用户已授权把本仓库改为 public，无需再次请求公开许可。当前未启用 Pages 的 404 不能单独证明账户不具资格。
3. 仅当数学架构确认生产需要 Python，且 Community Cloud 的资源／并发验证通过时选择 Streamlit。研究脚本为 Python 不构成必须采用 Streamlit 的理由。
4. 若保持 TypeScript 而客户端算力不够，使用用户 AWS 承载同一求解器并保留 React。仅更换静态托管时复用原构建产物；增加远端计算时补执行 Adapter，避免两套生产规则。

网页面向所有玩家公开，无需登录。私有源码并不能隐藏浏览器下载的计算代码／静态数据。游戏原始二进制、本机缓存与凭据不发布。
